# 💼 Ledgerly Dashboard

En stilren och interaktiv kryptoplånbok UI – inspirerad av Phantom – byggd med HTML, CSS och JavaScript.

---

## 🚀 Funktioner

- 👋 Välkomstkort med användarnamn
- 💰 Visning av saldo i BTC, ETH, SOL och USDC
- ⚡️ Snabbknappar för:
  - Receive
  - Send
  - Swap
  - Buy
- 🔁 Återanvändbar modal för alla actions
- 📈 Marknadsdata för de största kryptovalutorna
- 🧾 Lista med senaste transaktioner
- 🌙 Light/Dark Mode toggle
- 🔍 Sökikon som länkar till [CoinGecko](https://www.coingecko.com)

---

## 🛠 Tekniker

- **HTML5** – Semantisk och strukturerad markup
- **CSS3** – Responsiv och modern design
- **JavaScript (Vanilla)** – Dynamiska interaktioner och modaler
- **Chart.js** – För balanshistorik (kan aktiveras senare)
